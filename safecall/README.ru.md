# Safecall

**Ничего не записывается, пока нет копии. Ничего не читается, пока вы не увидели список.
Ни один ответ не кончается без строчки о том, чего никто не проверял.**

Плагин для [Claude Code](https://claude.com/claude-code) — для человека, который не программист,
у которого на компьютере лежат его собственные документы и у которого есть две причины не
подпускать к ним ИИ:

1. *а вдруг он сотрёт мои файлы*
2. *а вдруг он уверенно скажет неправду, и я на этом что-то сделаю*

Safecall закрывает обе и добавляет три разбора, которые такому человеку нужны на самом деле.

## Что он делает

| | |
|---|---|
| `/safecall:before` | Показывает список папки и ждёт, прежде чем читать. Копирует каждый файл, который собирается менять. |
| `/safecall:undo` | Возвращает файлы, как было. Сам возврат тоже можно отменить. |
| `/safecall:show` | Говорит, что изменится, **до** того, как изменит, — по смыслу, а не строками с плюсами. Потом говорит, где что лежит. |
| `/safecall:receipt` | Три строки под ответом: проверил · **не** проверял · откуда. |
| `/safecall:traps` | Где подвох в договоре, кредите, страховке, смете — и к каждому пункту цитата из бумаги. |
| `/safecall:holes` | Чего не хватает в плане. Три вопроса, а не тридцать. |
| `/safecall:facts` | Что здесь можно проверить, что мнение, а что вообще ничего не значит. |
| `/safecall:where` | Поднимает, на чём остановились в прошлый вечер, и записывает, на чём кончился этот. |
| `/safecall:doctor` | Почему ИИ молчит — словами, по одному шагу. |

Два тихих крючка:

- **при запуске** — настоящие дата и время этого компьютера (иначе ИИ желает доброй ночи в десять
  утра) и строчка «где мы остановились»;
- **перед записью в уже существующий файл** — проверка, что копия есть. Новый файл не
  останавливается никогда, чтение не останавливается никогда, про один файл напоминается один раз.

## Установка

```
/plugin marketplace add vadimchernets/safecall
/plugin install safecall@safecall
```

Потом в `/plugin` → Marketplaces **включите автообновление**: для чужих каталогов оно выключено по
умолчанию, и без него вы навсегда останетесь на той версии, которую поставили.

## Где лежат копии

`~/.safecall/снимки/` — **вне** вашей папки, и внутри лежит записка с просьбой не удалять.
Копия рядом с документами читается как мусор, и её выбрасывает ровно тот человек, которого она
защищает. Копии старше 14 дней стираются сами, на папку хранится не больше 20, файл не больше
5 МБ, копия не больше 50 МБ.

**Файлы, в имени которых есть слово про пароль или ключ, не копируются вовсе** — копия секрета
это второй секрет, а эта папка охраняется не так, как оригинал.

## Чего он не делает — и чего он не может обещать

**Сам Safecall** в сеть не ходит, аккаунтов и ключей не просит, вторую программу ставить не
требует. Всё, что он пишет, лежит на вашем диске, и всё это можно открыть и прочитать. Нужен
только Python 3.8+.

**Но Safecall не делает Claude Code приватным, и притворяться этим плагин не будет.** Документ,
который вы дали Claude Code, уходит на прочтение в Anthropic — так устроен сам Claude Code, с этим
плагином и без него. Safecall решает, **можно ли вернуть файл обратно**, а не **куда он уходит**.
Поэтому старое правило в силе, и умение `/safecall:before` говорит его вслух: не давайте папку,
которую не отправили бы письмом чужому человеку. Что показывать, а что придержать — отдельный
вопрос, и плагин помогает его задать, а не отвечает на него за вас.
